# Card Walk（刷卡）

[English](./README.md) · **简体中文**

界面跟着 Obsidian 的语言（中文 / 英文）。从作者的「第二大脑」插件里拆出来的，设计稿见 [DESIGN.md](./DESIGN.md)。

从库里抽 `#card` 卡片和 `==挖空==`，在侧栏一张张刷：先只看问题，揭开，按「重来 / 困难 / 良好 / 简单」作答，排程走 Anki。手机上也能刷，作答几秒内就进电脑上的 Anki，而且每一步都摆在界面上。

## 刷卡

- 左侧栏的卡片堆图标或命令「打开刷卡」。可以设成每天第一次打开 Obsidian 时在右侧栏自动放一个标签（不抢焦点）。
- **卡片**：`#card` 所在的列表项连同子项，第一行是问题，子项是答案。**挖空**：`==…==`、`{{c1::…}}`、`{1:…}` 遮成［⋯］，编号规则和 Flashcards 一致；一条笔记在 Anki 里有几张卡时，只遮这次要复习的那个空。按 Markdown 渲染，图片、表格、链接都正常显示；卡片上方是包着它的各层母块。
- **抽卡**：Anki 今天到期的排最前，其余卡片和挖空轮流来。同一天抽到的固定，↻ 换一批。按新增时间圈范围（7 天 / 1 个月 / 全部），按「学科」筛，设了语言规则还有单独的「语言」分类。近一年的、链到指定页面的可以加权。
- **每日目标**：一张卡第一次揭开或作答算一张，顶上进度条和最近 14 天的小方块（Anki 的复习记录，手机上答的也算）。刷够了就收工，「再来 10 张」接着刷。答「重来」的卡隔三张再出来一次。
- **键盘**：点一下选中，Space 揭开，1-4 作答，↑↓ 换一张；⌥⌘→ 聚焦只看一张，⌥⌘← 或 Esc 退出（键位跟着 Bullet 的 Zoom）。⌘ 点击打开原文并选中那一行。
- **右键 → 不再作为卡片**：去掉 `#card` 或挖空标记，文字原样留着，可以撤销。
- **作答反馈**：答对一小段往上走的音 + 一簇小烟花，连对音一次比一次高；答错一记低沉的。都在设置里能关。
- **复习计时**（可选）：一轮复习在今天日记顶部记一行 `DONE 14:10-14:12 复习卡片 23 张（作答 18 · 重来 2 · 只看 5）`，螺旋日程用青色画出来。格式可以改。用时按真实时间：每张从上一次操作算到这次，一张最多 60 秒，也写进 Anki 的复习记录；中途走开点面板顶上的 ⏸，表停。

## 手机和电脑之间的同步

刷卡进度在两台设备之间要**实时**、而且**看得见**：刷的时候心里得有底——这张卡的进度是不是最新的？是不是在刷一张电脑上已经答过的旧卡？手机上答的到底进 Anki 了没有？

如果靠 iCloud 之类的文件同步，什么时候到、到没到都看不见。Card Walk 走一个 [Upstash](https://upstash.com) Redis 当中转站（免费档就够）：

- **手机上作答** → 当场推到中转站 → 电脑几秒内取下来写进 Anki → 新的进度推回中转站 → 手机拿到。手机在刷时电脑每 5 秒看一次，平时 30–60 秒，所以刚打开面板后的第一次作答，最慢要等一分钟左右电脑才发现。
- **两边面板顶上一条同步状态**，点开有设备列表和最近的作答：
  - 🟢「电脑在线 · Anki 开着 · 进度 3 秒前对齐」——手机上的卡就是 Anki 里的最新状态。
  - 🟡「电脑 2 小时前下线 · 用的是那时的进度」——电脑关着就没人改 Anki，进度仍然准；手机上答的先排队，电脑上线后补进去。
  - 🟡「电脑在线，但 Anki 没开 · 作答先排队」。
  - 🔴「连不上中转站 · 3 张存在本机，联网后自动传」。
  - 电脑上：「📱 iPhone 刚刚在刷 · 今天从手机补进 Anki 12 张」。
- **每次作答三格**：已记 → 中转 → Anki（3 天后），实时变色。手机上没网时答的先存在本机（不进库、不走 iCloud），联网后自动补传，不会重复作答。
- **防刷旧卡**：手机一拿到新进度，就重查面板上每张卡能不能答；刚在别处答过的卡当场变灰，标「进度刚更新：已经在别处答过」。电脑上，手机已经答了、还没补进 Anki 的卡也不让再答。
- **上传的只有**卡号、作答等级、时间、设备名和 Anki 进度快照（卡号列表），不传卡片内容。

### 怎么开

1. 在 [console.upstash.com](https://console.upstash.com) 开一个 Redis 库（或 Vercel Marketplace 里的 Upstash for Redis），在库的页面复制 REST URL 和 token（不是只读的那个）。
2. 设置 → 手机同步：填 REST 地址和 token，点「测试连接」。两台设备填同一个库；设置跟着库同步的话填一次就够。
3. 设备名只存在本机，同步状态里显示。

没开同步时：电脑上照常直接用 Anki；手机上能看卡，不能作答。

## 依赖

- [Anki](https://apps.ankiweb.net) + [AnkiConnect](https://ankiweb.net/shared/info/2055492159)：作答写进 Anki（电脑上要开着）。每张的用时要给 AnkiConnect 打补丁才记得上（`answerCards` 里 `card.start_timer()` 之后加 `card.timer_started -= duration`），打过补丁的打开「核对用时」。
- [Flashcards](https://github.com/reuseman/flashcards-obsidian)：把卡片同步进 Anki，并把「块 id → Anki 笔记 id」写进笔记属性 `flashcards`，这个插件靠它认出每张卡在 Anki 里是哪条。
- Upstash Redis：可选，手机同步用。
- 第二大脑：可选。装了就借它的本机向量，把没挂学科双链的卡按意思归到最像的学科。

## 安装

在 设置 → 第三方插件 里搜 **Card Walk**；或者从 [Releases](https://github.com/MatsuriMW/card-walk/releases) 下载 `main.js`、`manifest.json`、`styles.css` 放进库里的 `.obsidian/plugins/card-walk/`。也可以用 BRAT：`MatsuriMW/card-walk`。

## 网络

只连你电脑上的 AnkiConnect（默认 `http://127.0.0.1:8765`），以及你自己设置的 Upstash 库，没有别的请求，也不收集使用数据。
